Nosso objetivo é criar um gerador procedural de fichas de jogadores para Pathfinder 2E, irá desde a matemática básica dos atributos até os últimos detalhes para a finalização de personagem, deixando a ficha pronta para o jogador usar.
Iremos criar ele em Flask para todo o projeto. Como o pdf tem tabelas e colunas e caixas de texto caso você ache necessário use as ferramentas que lhe forem melhor para a leitura. Use apenas o "ref\P Basic 2.0 Teste.pdf" para extrair as informações que precisamos e ignore os demais pdfs da pasta.
Use a pasta "templates" para colocar os arquivos do Front End, e use a pasta "dados" para colocar as informações, convertidas em json, da ficha, classe, raça, atributos, habilidades, talentos, magias, equipamentos e quaisquer demais características que sejam ligadas a ficha do jogador. Se achar necessário, crie arquivos para extração do pdf, para ajudar na leitura e entendimento das informações do pdf "ref\P Basic 2.0 Teste.pdf"
